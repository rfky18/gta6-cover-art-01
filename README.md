GRAND VICE CITY — Cover Studio: an offline GTA 6-style multi-panel cover art maker. Upload your photos, pick one of 7 original cover presets (including the Poster Ink halftone grade), drag, crop and grade every panel, then export a print-ready PNG in 1080×1080, 1080×1350 or 1920×1080 — all processing happens locally in your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the studio loads with the One Subject Poster Ink cover ready to export.
